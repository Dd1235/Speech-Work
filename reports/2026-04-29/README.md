# report_apr29

LaTeX report for the April 29 update: per-phone Gaussians + MCMC cores + DBSCAN + N-way K-shot support set, all 39 phoneme classes.

## Files

- `report.tex` — main LaTeX document. Self-contained; references images in `assets/` via relative paths.
- `extract_outputs.py` — pulls figures and tables out of `../dbscan_40phone_mcmc_gmm_dim12.ipynb` cell outputs into `assets/` and writes a markdown dump (`report_dump.md`) for sanity-checking.
- `assets/` — PNG figures referenced by `report.tex`.
- `report_dump.md` — generated by `extract_outputs.py`; not needed for compilation.

## Workflow

1. **Run the notebook end-to-end.** All 9 figures referenced in `report.tex` come from named cells in `dbscan_40phone_mcmc_gmm_dim12.ipynb`. If any cell is unrun, its image will be missing from `assets/` and LaTeX will warn.
2. **Re-extract assets:**
   ```
   cd report_apr29
   python extract_outputs.py
   ```
   This re-populates `assets/` with the latest figures. Idempotent.
3. **Upload to Overleaf.** Drag the entire `report_apr29` folder (including `assets/`) into a new Overleaf project. Set `report.tex` as the main document. Compile with pdflatex.
